## 1. What is supported

### `P7` — the window-substitution certificate *(theory)*
**Pointwise, for every shot and every label `Y`, an exact identity on the loss indicators:**

> `|1{Split_b ≠ Y} − 1{Joint ≠ Y}| = 1{Δ_b}`

Taking expectations and applying `|E X| ≤ E|X|` gives the certificate
`|R(Split_b) − R(Joint)| ≤ Pr[Δ_b]`. Assumption-free: valid under arbitrary decoder
misspecification, because it never models the decoder.

🔴🔴 **THE BOUND ON RISKS IS NOT AN EQUALITY.** It is attained in the worst case over
labels — `sup_Y |R(Split_b) − R(Joint)| = Pr[Δ_b]` — and, for a *fixed* label distribution,
only when every disagreement favours the same decoder, so that harmful and beneficial
disagreements do not cancel. **This project cannot check that condition**: absolute logical
error rates were withdrawn with `B11`, so the sign of each disagreement is unknown here.
Earlier versions of this file wrote "an equality when `S ≠ J`" against the *risk*
inequality. That was wrong; the equality belongs to the pointwise loss-indicator identity
above. Found by cross-model consultation 2026-08-30, after six audits had passed it.

🔴 **It bounds a policy by `Pr[output ≠ Joint]` for that policy's own output.** Dropping
escalated shots is licensed only when the escalated output *is* the joint output. That
mistake has been made twice here and is the most common way to misuse this result.

### `E2` — the maximal graphlike class is excluded *(device, four contexts)*
For independent events firing at `p_e <= 1/2` and flipping detector set `S_e`, with
`psi_e = -log(1 - 2 p_e) >= 0` and `omega_A = -log E[prod_{i in A} (-1)^{D_i}]`, the quantity
`c_ij = (omega_i + omega_j - omega_ij)/2` equals `sum_{e contains both i,j} psi_e`. For the **maximal**
graphlike class -- every singleton and **all** detector pairs, no geometry chosen by us -- the moments are
realizable **iff** `c_ij >= 0` and `sum_j c_ij <= omega_i`, whence `G_same = 2 T_same - B <= 0` is a theorem.

🔴 **What this licenses**: no reweighting of the fitted graph, no added local or long-range pair edge, and no alternative pair-edge topology reproduces these moments. 🔴 **What it does not**: a physical mechanism, leakage, a unique hyperedge structure, that all independent-event models fail, or that any graphlike model fails to reproduce `Delta_b`.
